# tradexag.ch

Statische Webseite der TradeX International AG, ausgeliefert über GitHub Pages (Branch `main`, Ordner `/`).

- `index.html`: die Seite (Deutsch/Englisch)
- `impressum.html`, `datenschutz.html`, `404.html`
- `assets/`: Schriften (selbst gehostet) und Porträt
- `llms.txt`: Kurzbeschreibung und Linkliste für KI-Suchen (llmstxt.org), bei neuen Seiten mitpflegen
- `CNAME`: eigene Domain tradexag.ch
